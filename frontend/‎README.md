🎮🍿 Backlogger — Універсальна платформа для геймерів та кіноманів

Backlogger — це повнофункціональний вебзастосунок для ведення особистої колекції відеоігор, фільмів, серіалів та аніме, синхронізації бібліотеки зі Steam, гейміфікації прогресу (рівні, XP, досягнення, тір-лісти, рулетка беклогу), спілкування у спільноті та отримання персональних рекомендацій від вбудованого ШІ-помічника.

🛠️ Технологічний стек

Frontend: React (Vite), Tailwind CSS, Framer Motion, Lucide Icons, Axios, React Hot Toast.

Backend: Node.js, Express.js, JWT (JSON Web Tokens), Bcrypt.js.

База даних: MongoDB + Mongoose ODM.

Зовнішні інтеграції (API): RAWG API (каталог ігор), TMDB API (каталог кіно, серіалів та аніме), Steam Web API (імпорт ігор та годин), Groq API (ШІ-порадник).

📋 Передумови перед запуском

Переконайтеся, що на вашому комп'ютері встановлено:

Node.js (рекомендована версія v18.x або новіша) — Завантажити Node.js

Git — Завантажити Git

MongoDB — локально встановлений сервер MongoDB Community або безкоштовний хмарний кластер у MongoDB Atlas.

🚀 Покрокова інструкція встановлення залежностей

1. Клонування репозиторію

Відкрийте термінал та виконайте команди:

git clone <ПОСИЛАННЯ_НА_ВАШ_GITHUB_РЕПОЗИТОРІЙ>
cd backlogger

2. Встановлення залежностей для Backend (серверна частина)

Перейдіть у папку backend та встановіть усі необхідні npm-пакети:

cd backend
npm install

3. Встановлення залежностей для Frontend (клієнтська частина)

Відкрийте другий термінал (або поверніться в корінь проєкту), перейдіть у папку frontend та встановіть пакети:

cd ../frontend
npm install

🔐 Налаштування змінних оточення (.env)

Для коректної роботи проєкту необхідно створити файли конфігурації .env.

1. Файл backend/.env

Створіть файл з назвою .env всередині папки backend/ та додайте скопіюйте дані з env.example

2. Файл frontend/.env (опціонально для локальної розробки, обов'язково для продакшену)

У папці frontend/ можна створити файл .env:

VITE_API_URL=http://localhost:5000
VITE_MONO_JAR_URL=https://send.monobank.ua/jar/6DBycstjdj


🗄️ Налаштування бази даних

Проєкт використовує документоорієнтовану базу даних MongoDB разом із бібліотекою Mongoose (замість реляційної Prisma ORM).

Міграції чи команди на кшталт npx prisma generate не потрібні — Mongoose автоматично створює всі необхідні колекції (users, items, playlists, discussions) та індекси при першому старті сервера.

Якщо ви використовуєте локальну MongoDB, переконайтеся, що служба MongoDB запущена на вашому ПК, і вкажіть у backend/.env:

MONGO_URI=mongodb://127.0.0.1:27017/backlogger


Якщо ви використовуєте MongoDB Atlas, переконайтеся, що у вкладці Network Access в панелі керування Atlas додано вашу IP-адресу (або відкрито доступ 0.0.0.0/0).

▶️ Запуск проєкту

Для повноцінної роботи потрібно одночасно запустити Backend та Frontend у двох окремих вікнах термінала.

Крок 1: Запуск сервера (Backend)

У першому терміналі перейдіть у папку backend:

cd backend
npm run dev


(Для продакшен-запуску без nodemon використовується команда npm start).
Ви побачите повідомлення:

Сервер працює на порту 5000

Базу даних MongoDB успішно підключено!

Крок 2: Запуск клієнта (Frontend)

У другому терміналі перейдіть у папку frontend:

cd frontend
npm run dev


Після запуску відкрийте у браузері посилання, яке покаже Vite:
👉 http://localhost:5173
